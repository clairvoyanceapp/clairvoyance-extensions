# Clairvoyance Extensions

Extensions (CAMs) for [Clairvoyance](https://www.clairvoyanceai.com). An extension can add a Command Bar icon, a sidebar, and tabs. Each folder is one extension: an `extension.yaml` manifest plus its HTML, CSS, and JavaScript.

## Install

Install from the Clairvoyance **Gallery**, or download the `.cvextension` file from this repository's [Releases](https://github.com/clairvoyanceapp/clairvoyance-extensions/releases) and install it in **Settings → Features**.
